# App Insights Unlocked: Google Play Store EDA (`EDA01`)

Exploratory Data Analysis (EDA) on the Google Play Store Apps dataset (`n = 9,659` unique apps after cleaning) to uncover patterns in app ratings, install volumes, pricing, update frequency, and category/genre performance.

## Project Overview
* **Objective:** Identify key drivers of app user satisfaction and download volume across Basic, Medium, and Advanced analytical benchmarks.
* **Dataset:** Google Play Store Apps (`googleplaystore.csv` — cleaned from 10,841 raw rows to 9,659 unique apps).
* **Tools & Libraries:** Python, pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook (VS Code).
